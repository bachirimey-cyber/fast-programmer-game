❓ Beginner help

Digital signals: everything is 1 (ON / high / true) or 0 (OFF / low / false). A wire is green when it carries 1.

Parts

  • Switch (input): you control it. Click it to flip 0 ↔ 1. The first switch is A, the second is B...
  • LED (output): the lamp that shows the result. It lights up when it gets 1.
  • Pin: the small circle on a part. Left pins = inputs, right pin = output.
  • Wire: click an output pin, then an input pin. One output can feed many wires. Each input takes one wire.

Logic gates

NOTflips the signal: 1→0, 0→1
AND1 only if all inputs are 1
OR1 if at least one input is 1
NANDthe opposite of AND
NORthe opposite of OR
XOR1 if the inputs are different

How to solve a task

  1. Read the task.
  2. Add the switches, gates and LED from the toolbar.
  3. Wire them: switch → gate → LED.
  4. Click the switches to test it.
  5. Press Check. It tries every combination (a truth table) and tells you which rows are wrong.

Words

Circuit: connected parts. Truth table: all input combinations with the output for each. Logisim: a free program for drawing logic circuits, which this game copies in a simple way.
